DEVICE
PANGOLIN
HOW DO I GET A KEY?

Pangolin dashboard → your organisation → Settings → API Keys → Generate.

Give it exactly three permissions, using Organization scope — not a root key, and never "Allow All Permissions":

  • Site → List Sites
  • Resource → List Resources
  • Resource → List Site Resources

The key is shown once — copy it before you leave the page. It cannot be read back afterward.

The API URL above is just the host — this app adds /v1 itself.

TRUENAS
HOW DO I GET A KEY?

TrueNAS 25.04 changed API keys to inherit the privileges of the account that made them — a key made on your admin account can do anything your admin account can. Make a restricted account instead:

  1. Credentials → Users → Add. Create a service account, e.g. hc1-dashboard.
  2. Give it the READONLY_ADMIN role — this is what makes the key read-only.
  3. Sign in as that account, then top-right user menu → My API Keys → Add.

The key is shown once — TrueNAS will not show it again after you leave the page.

JELLYFIN OPTIONAL — REQUIRED FOR THE RESUME AND UP NEXT WIDGETS
HOW DO I GET A KEY?

Jellyfin Dashboard → Advanced → API Keys → "+".

Jellyfin has no read-only key type, unlike Pangolin and TrueNAS — this key can technically do more than this dashboard needs. Said plainly: this app only ever makes read requests, never writes anything.

The key is shown once when you create it — copy it before you navigate away.

The USER field above decides whose "continue watching" and "up next" lists appear on the dashboard.
